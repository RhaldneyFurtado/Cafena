# ☕ Coffee Shop - Página Web Interativa

Uma página web moderna e responsiva para cafeteria, desenvolvida exclusivamente com **HTML5, CSS3 e JavaScript puro**. 

O projeto apresenta a vitrine de produtos de uma cafeteria com navegação fluida, busca e filtragem em tempo real, além de um carrinho de compras funcional na barra lateral (sidebar).

---

## Funcionalidades

- **Busca e Filtragem em Tempo Real:** Pesquisa dinâmica no cardápio de produtos sem recarregar a página.
- **Carrinho de Compras Lateral (Sidebar):** Adição, remoção, alteração de quantidades e atualização de itens em tempo real.
- **Design Responsivo:** Layout adaptado para boa visualização em celulares, tablets e desktops.
- **Interatividade & UX:** Manipulação limpa da interface e feedback visual para as ações do usuário.

---

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização responsiva (Flexbox / CSS Grid), estilização de temas e animações.
- **JavaScript (ES6+):** Manipulação de DOM, escutadores de eventos e lógica de filtragem/carrinho.
